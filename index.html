Projects

DataEval

Lead engineer · Open source

A Python library for analyzing data quality and its impact on ML model performance — covering bias, coverage, drift, divergence metrics, and outlier detection across classification and object-detection workflows. Funded by the DoD's Chief Digital and AI Office (CDAO), shipped on PyPI, and built on the MAITE protocol for interoperability with the broader T&E ecosystem.

I own the modular evaluation pipelines, the CI/CD and dependency story (including the Python 3.14 modernization), the Sphinx documentation and contributor guides, and the architectural standards that turned a research codebase into reliable infrastructure. I also lead several adjacent projects in the aria-ml ecosystem.

One of those is DataEval Flow — a YAML-configurable orchestration layer that wraps DataEval for production use. GPU and CPU container builds, headless execution for CI/CD, and a Textual-based TUI for interactive config and result review. Schemas are auto-discovered from torchvision transforms, DataEval selection classes, and workflow types, so the surface stays in sync with the library underneath.

ATLAS — Secure agentic AI platform

Architect · Internal

A self-hosted code-assist platform built around open-source models and weights, with retrieval-augmented generation and persistent memory for long-running agentic workflows. Designed to operate in CMMC 2.0-compliant environments and support air-gapped deployment for secure compute. Inference is served through vLLM behind a LiteLLM gateway, deployed on a multi-node Kubernetes (K3s) topology that separates compute from control plane.

Provisioning is fully declarative — OpenTofu / Terraform for infrastructure, Ansible for configuration — with telemetry, dashboards, and monitoring wired in from day one. The goal is a code-assist stack that secure teams can actually own: open weights, observable behavior, and no third-party dependency for the things that matter.
